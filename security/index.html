보안과 데이터

Sentrix와 Sentrix HR에서 누가 무엇을 보는지, 위치와 기록을 어떻게 다루는지 정리했습니다. 자세한 내용은 제품별 개인정보처리방침에 있습니다.

  • 역할별 조회 범위본사는 회사 전체, 팀장은 자기 지점만 봅니다.
  • 승인된 기기로 로그인새 기기는 팀장 승인 뒤에 씁니다.
  • 위치는 출퇴근 순간에만출퇴근 버튼을 누를 때 한 번만 위치를 확인해 근무지 반경 안인지 판단합니다. 위치를 계속 따라가지 않습니다.
  • 역할이 바뀌면 다시 로그인회사와 지점 단위로 볼 수 있는 범위를 나누고, 역할이나 권한이 바뀌면 로그인을 다시 하게 합니다.
  • 암호화해 저장비밀번호, 생년월일, 경비원 신임교육 이수번호는 암호화해 저장하고, 주민등록번호는 받지 않습니다. 모든 통신은 HTTPS로만 주고받습니다.
  • 기록은 남기고 점검로그인 시도 횟수를 제한하고, 접속과 변경 기록을 2년 동안 보관해 점검합니다.
  • 서버는 Microsoft Azure서버와 데이터베이스, 첨부 파일은 출입 통제가 이루어지는 Microsoft Azure 데이터센터에 둡니다.
  • AI 도우미는 가리고 보냅니다전화번호는 보내기 전에 가리고, 질문과 답변 원문은 서버에 남기지 않습니다. 입력한 내용은 모델 학습에 쓰지 않습니다.
  • 계약이 끝나면 돌려드리고 파기직원 · 근무 정보의 처리자는 고객사입니다. 계약이 끝나면 고객사에 돌려드린 뒤 파기합니다.
